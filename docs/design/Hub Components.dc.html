Status vocabulary

one ink + surface + border per state
→ Pending → Running → Intervention-Requested → Interactive-User → Completed-Success → Completed-Failed → Completed-Error → Completed-Stale → Completed-Cancelled
Moss is healthy, rust means a human is needed, indigo means a human or the model is driving, red is terminal failure, grey is inert. The same triplet drives the strip's status cell, the transcript rail, and this badge.

Buttons

button-base + button-variant-{primary, secondary, caution, danger, tinted($color)}
One size (32px). Caution is separate from danger: rust asks a human to act on a stuck job, red destroys or ends something. button-variant-tinted($color) takes any status ink for actions that belong to a state.

Icon buttons

button-icon-bare · button-icon-outlined — a separate mixin, not a button variant
bare · inline in a dense strip
outlined · scannable in a log row
outlined · overlay dismiss
Kept out of the button mixin deliberately: it is square, label-less, 20–22px rather than 32px, and carries no horizontal padding or min-width. Composing it from button-base would mean overriding height, padding, min-width, gap and font-size at every call site.
