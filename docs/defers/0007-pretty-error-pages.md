# DEFER 7: Pretty 404/500 pages and API 404 messaging

## What?
Friendly 404 and 500 pages in the Hub UI, and clear messages for unexpected API 404 responses (for example a Job id that is not found), were not built. Errors currently surface through the framework defaults.

## Why?
The system is at proof-of-concept stage and these can be added later with little rework. Revisit when the Hub is exposed to users beyond the POC audience.
